# WebShield

A Python tool for checking website security configurations.

## Project Status
In development.

## Planned Features
- Check for missing HTTP security headers.
- Inspect HTTPS redirects.
- Check cookie security attributes.
- Explain findings and recommend fixes.
- Export findings to a JSON report.

## Learning Goals
Understand HTTP requests and responses, implement security checks
in Python, and demonstrate how to identify and fix configuration issues.
